==== tbl_res_calendar
  trc_id INTEGER - รหัสของตารางเก็บข้อมูลทะเบียนวาระการประชุม
  trc_name VARCHAR(10) - การประชุมครั้งที่
  trc_date DATE - วัน เดือน ปี ที่ประชุม
  trc_start_time VARCHAR(5) - เวลาที่เริ่มการประชุม เช่น 09:45
  trc_end_time VARCHAR(5) - เวลาที่สิ้นสุดการประชุม เช่น 12:00
  trc_status CHAR(1) - สถานะ (1=active, 2=inactive)
  is_deleted BOOLEAN - Soft Delete Flag (1=Delete, 0=Not Delete)
  created_datetime TIMESTAMP - วันเวลาที่สร้างข้อมูล
  created_by INTEGER - ผู้สร้างข้อมูล
  updated_datetime TIMESTAMP - วันเวลาแก้ไขข้อมูลล่าสุด
  updated_by INTEGER - ผู้แก้ไขข้อมูล
==== tbl_res_calendar_item
  trci_id INTEGER - รหัสของตารางเก็บข้อมูลรายการของทะเบียนวาระการประชุม
  trc_id INTEGER - FK → tbl_res_calendar.trc_id
  trci_number VARCHAR(10) - วาระการประชุมที่ เช่น 5.20
  trci_topic VARCHAR(255) - ชื่อเรื่องเสนอพิจารณา
  is_deleted BOOLEAN - Soft Delete Flag (1=Delete, 0=Not Delete)
  created_datetime TIMESTAMP - วันเวลาที่สร้างข้อมูล
  created_by INTEGER - ผู้สร้างข้อมูล
  updated_datetime TIMESTAMP - วันเวลาแก้ไขข้อมูลล่าสุด
  updated_by INTEGER - ผู้แก้ไขข้อมูล
==== tbl_res_request
  trr_id INTEGER - รหัสของตารางเก็บข้อมูลรายการร้องขอมติคณะกรรมการ
  tcc_id INTEGER - รหัสของตารางเก็บข้อมูลการรับเรื่องร้องเรียน (tbl_cmp_case)
  trr_module CHAR(2) - module ต้นทาง (04=กจ4,05=กจ5,06=กจ6,07=กจ7,08=กจ8,09=กจ9,10=กจ10,11=กจ11,12=กจ12,13=กจ13,14=กจ14,99=อื่นๆ)
  trr_function CHAR(2) - Function ต้นทาง
  trr_status CHAR(3) - สถานะ (000=รอมติ)
  is_deleted BOOLEAN - Soft Delete Flag (1=Delete, 0=Not Delete)
  created_datetime TIMESTAMP - วันเวลาที่สร้างข้อมูล
  created_by INTEGER - ผู้สร้างข้อมูล
  updated_datetime TIMESTAMP - วันเวลาแก้ไขข้อมูลล่าสุด
  updated_by INTEGER - ผู้แก้ไขข้อมูล
==== tbl_res_request_item

  trr_id INTEGER - FK → tbl_res_request.trr_id
