## 9. ข้อจำกัดของข้อมูลชุดนี้

- ข้อมูลทั้งหมดเป็นข้อมูลสมมุติ ไม่ได้ดึงจาก API จริง ชื่อโครงการ หน่วยงาน และบริษัทไม่ได้อ้างอิงของจริง
- ระบบภาษีไปไหนเปิดเผยเฉพาะ **ผู้ชนะการเสนอราคา** ไม่มีข้อมูลผู้เข้าร่วมเสนอราคารายอื่นและราคาที่ยื่น จึงยังวิเคราะห์พฤติกรรมการฮั้วประมูลไม่ได้ (ดูกล่องล็อกใน Modal วิเคราะห์ความเสี่ยง)
- ข้อมูลจริงจาก DGA มีดีเลย์ ไม่ใช่เรียลไทม์ เหมาะกับงานสืบสวนย้อนหลัง ไม่เหมาะกับการเฝ้าระวังแบบทันที
- โควตาการเรียก API จริงจำกัด 1,000 ครั้ง/วัน ต่อหนึ่ง API Key
