## 3. ตัวอย่างการเรียกใช้จริง (curl)

แทนที่ `{{TOKEN}}` ด้วย Token ที่ได้รับจากผู้ดูแลระบบ E-CMIS และ `{domain}` ด้วยโดเมนของระบบ

### กลุ่มที่ 1 จัดซื้อจัดจ้าง (e-GP)

```bash
# 1 ข้อมูลโครงการจัดซื้อจัดจ้าง
curl -X GET "https://{domain}/open/api/govspending/2.0/cgdcontract?year=2568&keyword=ก่อสร้าง&dept_code=0800&budget_start=0&budget_end=400000000&offset=0&limit=20" \
  -H "Authorization: Bearer {{TOKEN}}"

# 2 ผลสรุปโครงการจัดซื้อจัดจ้าง
curl -X GET "https://{domain}/open/api/govspending/2.0/summary_cgdcontract?year=2568&dept_code=0800" \
  -H "Authorization: Bearer {{TOKEN}}"

# 3 รายชื่อหน่วยจัดซื้อ
curl -X GET "https://{domain}/open/api/govspending/2.0/egpdepartment?dept_name=กองทัพ&offset=0&limit=20" \
  -H "Authorization: Bearer {{TOKEN}}"

# 4 รายชื่อหน่วยจัดซื้อย่อย
curl -X GET "https://{domain}/open/api/govspending/2.0/egpsubdepartment?sub_dept_name=สำนักสำรวจและออกแบบ&offset=0&limit=20" \
  -H "Authorization: Bearer {{TOKEN}}"

# 5 รายชื่อผู้ชนะการเสนอราคา
curl -X GET "https://{domain}/open/api/govspending/2.0/egpwinner?winner=อิตาเลียนไทย&offset=0&limit=20" \
  -H "Authorization: Bearer {{TOKEN}}"
```

### กลุ่มที่ 2 งบประมาณ

```bash

# 8 งบประมาณและการเบิกจ่าย
```

### การเรียกไปที่ต้นทางโดยตรง (สำหรับทดสอบเปรียบเทียบ)

ต้นทางของ DGA ยืนยันตัวตนด้วย `api-key` ใน Query String ไม่ใช่ Header ลงทะเบียนขอ API Key ได้ที่ https://opend.data.go.th/register_api

```bash
curl -X GET "https://opend.data.go.th/govspending/cgdcontract?api-key={{API_KEY}}&year=2568&limit=5"
```

## 5. เคสทดสอบฝั่ง API

| ลำดับ | สิ่งที่ส่ง | สถานะที่คาดหวัง |
| :--- | :--- | :--- |
| API-01 | เรียก cgdcontract พร้อม year และ Authorization ที่ถูกต้อง | 200 Successful พร้อม result เป็น Array |
| API-02 | เรียกโดยไม่ส่ง year | 400 Bad Requests |
| API-03 | เรียกโดยไม่ใส่ Header Authorization | 401 Unauthorized |
| API-04 | ใส่ Token ที่หมดอายุหรือผิด | 403 Token mismatches |
| API-05 | เรียก path ที่ไม่มีอยู่จริง | 404 Service not found |
| API-06 | ส่ง limit เกิน 1,000 | ระบบปรับให้เหลือ 1,000 หรือคืน 400 Bad Requests ตามที่ตกลงกับทีมพัฒนา |
| API-07 | ส่ง winner_tin ไม่ครบ 13 หลัก | 400 Bad Requests |
| API-08 | ส่ง budget_start มากกว่า budget_end | คืน 200 พร้อม result เป็น Array ว่าง |
| API-09 | เรียกเกินโควตา 1,000 ครั้งต่อวัน | 429 Quota exceeded |
| API-10 | ต้นทาง DGA ไม่ตอบสนอง | 500 Internal Server Error พร้อมข้อความใน msg |
