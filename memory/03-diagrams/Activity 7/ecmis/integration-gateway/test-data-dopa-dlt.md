# ข้อมูลทดสอบ — DOPA Linkage + DLT Linkage (ยานพาหนะ)

ใช้คู่กับ `index.html` แท็บ "ตรวจสอบประวัติบุคคล (DOPA Linkage)" → แท็บย่อย "ข้อมูลยานพาหนะ (DLT)"

ทุกเลขบัตรด้านล่างค้นได้ในช่อง "เลขบัตรประจำตัวประชาชน" หน้าแรก ระบบจะจัดรูปแบบขีดให้อัตโนมัติเมื่อพิมพ์ตัวเลขติดกัน

## 4. เลขนิติบุคคลในข้อมูลจำลอง (2 รายการ)

เลขทะเบียนนิติบุคคลไทยขึ้นต้นด้วย **0** เสมอ (ต่างจากเลขบัตรประชาชนที่ขึ้นต้น 1-8) ระบบตรวจจับรูปแบบนี้อัตโนมัติ

**พฤติกรรมของระบบเมื่อเจอเลขนิติบุคคล**

| จุดที่เจอ | สิ่งที่ระบบทำ |
| :--- | :--- |
| ค้นในแท็บ "ตรวจสอบประวัติบุคคล (DOPA)" | ขึ้นข้อความ "เลขนี้เป็นเลขทะเบียนนิติบุคคล" อธิบายว่า DOPA เก็บเฉพาะบุคคลธรรมดา ต้องเชื่อม DBD แยกต่างหาก — ไม่ใช่ข้อความ "ไม่พบข้อมูลบุคคล" แบบทั่วไป |
| ปุ่มย้อนกลับ DOPA จากหน้ารายละเอียดรถ | เปลี่ยนจากปุ่มกดได้ เป็น chip ข้อความ "ผู้ถือกรรมสิทธิ์เป็นนิติบุคคล — ต้องตรวจสอบผ่าน DBD" (กดไม่ได้ กันไม่ให้เจอทางตัน) |
| ค้นในแท็บ "ตรวจสอบทะเบียนรถ (DLT)" โหมด docNo | **ค้นได้ตามปกติ** เพราะสเปก DLT ระบุว่า docNo รับได้ทั้งเลขบัตรประชาชนและเลขที่นิติบุคคล |

## 5. โหมดค้นหาในหน้า "ตรวจสอบทะเบียนรถ (กรมการขนส่งทางบก)"

หน้าแยกนี้มี 2 โหมด สลับได้ที่ปุ่มด้านบน ตรงกับ 2 operation ที่เปิดสิทธิ์ใช้งานแล้วตามเอกสาร "รายละเอียด Web Service v2.0.0 - ปปท - v2.pdf"

| โหมด | Operation | Input ที่ใช้ | ผลลัพธ์ |
| :--- | :--- | :--- | :--- |
| ค้นจากทะเบียนรถ | `getVehicleInfoByPlate` | offLocCode, vehicleTypeRef, plate1, plate2 | รถ 1 คัน แสดงรายละเอียดเต็มในหน้าเดียว |
| ค้นจากเลขบัตร / เลขนิติบุคคล | `getVehicleInfoByDocNo` | docNo (13 หลัก) | รายการรถทั้งหมดที่ผูกกับเลขนั้น กดเลือกดูรายละเอียดทีละคัน |

โหมดค้นด้วย `docNo` รองรับทั้งเลขบัตรประชาชนและเลขทะเบียนนิติบุคคล ตามที่สเปกระบุว่า docNo คือ "เลขที่เอกสาร เช่น เลขบัตรประจำตัวประชาชน หรือ เลขที่นิติบุคคล เป็นต้น ที่ระบุในเล่มคู่มือรถ" จึงใช้ค้นรถของบริษัทได้โดยตรงโดยไม่ต้องผ่าน DOPA

### เคสทดสอบโหมดใหม่

## 6. Audit Log

ทั้ง 3 แท็บมีตาราง Audit Log ของตัวเอง บันทึกอัตโนมัติทุกครั้งที่มีการเข้าถึงข้อมูล ตามที่ตารางติดตามกิจกรรมที่ 13 กำหนดไว้ว่า "ทีม Dev ต้องพัฒนาระบบ Audit Log เก็บประวัติการค้นหาข้อมูลอย่างละเอียด"

| แท็บ | เหตุการณ์ที่บันทึก |
| :--- | :--- |
| ตรวจสอบประวัติบุคคล (DOPA) | สืบค้นบุคคล, นำข้อมูลเข้าสำนวน, ตรวจสอบยานพาหนะจากบุคคล, ค้นหาทะเบียนรถ, เปิดดูรายละเอียดยานพาหนะ, นำยานพาหนะเข้าสำนวน |
| ตรวจสอบทะเบียนรถ (DLT) | ค้นหาทะเบียนรถ, ค้นด้วยเลขบัตร/นิติบุคคล, เปิดดูรายละเอียด, ย้อนกลับไปตรวจสอบใน DOPA, นำยานพาหนะเข้าสำนวน |
| ตรวจสอบจัดซื้อจัดจ้าง (e-GP) | สืบค้นโครงการ, เปิดวิเคราะห์ความเสี่ยง, นำเข้าสำนวน, ส่งออกรายงาน |
