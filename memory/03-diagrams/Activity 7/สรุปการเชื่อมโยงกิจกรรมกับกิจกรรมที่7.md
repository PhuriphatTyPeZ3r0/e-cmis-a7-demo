> กิจกรรมที่ 7 = **"ศูนย์กลางมติบอร์ด (Board Resolution Hub)"** ทุกเรื่องที่ต้องมีมติคณะกรรมการ ป.ป.ท. จะวิ่งเข้า-ออกที่กิจกรรมนี้
> อัปเดต: 2026-07-20 | ที่มา: สรุปผู้รับผิดชอบแต่ละกิจกรรม

## รายละเอียดการเชื่อมโยง

### กจ.4 → กจ.7 (ขอมติบอร์ด) ➡️
- **รับเรื่องจาก ป.ป.ช. แล้วไม่รับไว้ไต่สวน** — การส่งคืนต้องผ่านมติคณะกรรมการ ป.ป.ท.
- **แยก/รวมสำนวน** — นักสืบเห็นว่าสำนวนมีหลายคดีซ้อน หรือหลายสำนวนควรรวมเป็นหนึ่ง ต้องเสนอบอร์ดลงมติก่อน

### กจ.5 ⬅️➡️ กจ.7 (input หลักของบอร์ด) — จุดเชื่อมสำคัญที่สุด
- **รายงาน 213** (รายงานการแสวงหาข้อเท็จจริง) → เลขาธิการ → เข้ามติบอร์ด (ทั้งชั้น**ไต่สวนเบื้องต้น**และ**ชี้มูล**) → นี่คือ input ที่บอร์ดในหน้า 7.1/7.2 พิจารณา
- **ขอแยกสำนวนเป็นคดีใหม่** — ต้องรอบอร์ดอนุมัติ
- **ผู้กล่าวหา/ผู้ถูกกล่าวหาขอทบทวนมติเดิม** — เข้าบอร์ดพิจารณาใหม่
- ⬅️ ขากลับ: มติ + คำสั่งแต่งตั้งคณะไต่สวน (จาก กจ.7) ส่งกลับให้ กจ.5 ดำเนินการ

### กจ.6 〰️ กจ.7 (เชื่อมทางอ้อม)
- คำขอคุ้มครอง / ขยายเวลา / ยุติการคุ้มครอง (คบ.1–16) **อนุมัติโดยเลขาธิการ ไม่ผ่านบอร์ด**
- กรณีเร่งด่วน ผอ.กอง หรือ ผอ.ป.ป.ท. เขต อนุมัติชั่วคราวก่อน แล้วเสนอเลขาธิการ
- ⚠️ **จุดเชื่อมกับ กจ.7 อ่อน** — อำนาจตัดสินอยู่ที่เลขาธิการ ไม่ใช่คณะกรรมการ

### กจ.7 (มติที่เกิดในตัวเอง) ⭐
- มติภายในองค์กรที่ไม่เกี่ยวกับเนื้อคดีโดยตรง: **ตั้งคน** (อนุกรรมการ) / **สั่งงาน** (ประธานสั่งตรง) / **ใช้เงิน** (เบี้ยประชุม) / **วางกฎ** (นโยบาย/รับรองรายงาน)
- อยู่ในโมดูลอย่างเป็นทางการ: **"มติเรื่องอื่นๆ"** (สำหรับเรื่องตั้งคน/สั่งงาน/นโยบาย) และโมดูล **"หนังสือทั่วไป"** (สำหรับเรื่องเอกสารธุรการ/เบิกเงินค่าเบี้ยประชุม)

### กจ.8 ⬅️➡️ กจ.7 (ปลายน้ำ + feedback loop)
- **8.1** — ไม่มีจุดเชื่อม
- **8.2 ติดตามสถานะคดี:**
  - ⬅️ **รับมติจาก กจ.7 → Trigger งานอัตโนมัติ** ใน Work Inbox + คำนวณ SLA ตามประเภทมติ:
    - ส่งอัยการ / ป.ป.ช. → ติดตาม **30 วัน**
    - ให้ไต่สวนเพิ่มเติม → ติดตาม **60 วัน** (ให้ กจ.5 ทำต่อ)
  - ➡️ **Feedback loop:** รวบรวมสถานะ → Executive Dashboard เสนอบอร์ด กจ.7 + แจ้งเตือนคดีล่าช้าให้บอร์ดเร่งรัด
- **8.3 ระบบการกำกับและตรวจสอบผลการดำเนินการทางวินัยฯ:**
  - ➡️ **Touchpoints วิ่งเข้าหา กจ.7:**
    - 1. เสนอรายงานผลการลงโทษทางวินัยให้บอร์ด ป.ป.ท. พิจารณารับทราบ/ดำเนินการเพิ่มเติม (ม.38)
    - 2. เสนอเรื่องขอทบทวนมติกรณีมีพยานหลักฐานใหม่ (ม.40)
    - 3. เสนอรายงานกรณีหน่วยงานต้นสังกัดเพิกเฉยไม่ดำเนินการลงโทษ เพื่อบอร์ดมีมติส่งเรื่องให้ ป.ป.ช. ดำเนินการ (ม.41)
    - 4. เสนอรายงานผลคำวินิจฉัยอุทธรณ์ของ ก.พ.ค./ก.พ.ค. ตร. ให้บอร์ดพิจารณามติ (ม.43)
    - 5. รายงาน/Dashboard สถิติภาพรวมการดำเนินการทางวินัยเสนอบอร์ดเพื่อรับทราบ

### กจ.9 〰️ กจ.7 (เชื่อมทางอ้อม)
- หนังสือยุติหมายจับ 3 กรณี (ตำรวจจับเอง / ป.ป.ท.ร่วมจับ / ตำรวจส่งตรงอัยการ) + รายงานผลจับกุม → **เลขาธิการรับทราบ/สั่งยุติ**
- ⚠️ **จุดเชื่อมกับ กจ.7 อ่อน** — เหมือน กจ.6 อำนาจอยู่ที่เลขาธิการ

### กจ.10 ⬅️➡️ กจ.7 (ขอมติบอร์ดหลายกรณี) — เชื่อมแน่นรองจาก กจ.5/8
- **10.1 เห็นชอบ/เห็นแย้งอัยการไม่สั่งฟ้อง** → นิติกรกลุ่มความเห็นแย้งวิเคราะห์ → เข้าบอร์ด กจ.7
  - เห็นชอบ → ยุติคดีอาญา | เห็นแย้ง → ส่ง **อัยการสูงสุด (อสส.)** วินิจฉัยชี้ขาด (ม.46)
- **10.2 อนุญาต/ไม่อนุญาตเปิดเผยข้อมูลข่าวสาร** → ผ่านคณะอนุกรรมการกลั่นกรองการเปิดเผยฯ → บอร์ด กจ.7
  - มติชั้นต้น + ชั้นอุทธรณ์ (ยื่นใน 30 วัน, บอร์ดพิจารณาให้เสร็จใน 60 วัน)
- **10.3 คดีปกครอง** → บอร์ด กจ.7
  - **มติมอบอำนาจสู้คดี** (ประธานลงนามใบมอบอำนาจ) + **มติอุทธรณ์/ไม่อุทธรณ์** (ไม่อุทธรณ์ = ปิดสำนวน)

## ข้อสังเกตสำหรับการออกแบบระบบ

1. **กจ.7 เป็น decision hub** — บอร์ดต้องรองรับ "ประเภทมติ" อย่างน้อย 3 กลุ่ม:
   - มติสำนวนคดี (รับ/ไม่รับ, ชี้มูล/ยุติ) ← จาก กจ.4, 5
   - มติทางกฎหมาย (เห็นชอบ/แย้งอัยการ, เปิดเผยข้อมูล, คดีปกครอง) ← จาก กจ.10
   - มติภายในองค์กร (ตั้งคน/สั่งงาน/เบี้ยประชุม/นโยบาย) ← กจ.7 เอง
2. **ความเชื่อมโยงสองทางที่ต้องออกแบบ interface ให้ดี:** กจ.5↔7 (สำนวน↔คำสั่ง), กจ.8↔7 (มติ↔dashboard/แจ้งเตือน), กจ.10↔7 (ผลอัยการ/ศาล↔มติ)
3. **กจ.6 และ กจ.9 เชื่อมอ่อน** — อำนาจตัดสินอยู่ที่เลขาธิการ ควรยืนยันว่าต้องมี touchpoint กับ กจ.7 หรือไม่
