## ✅ คำถามที่ตรวจสอบเพิ่มเติมแล้ว "คลี่คลาย" (ค้นลึกอีกรอบผ่าน NotebookLM)

1. **กองปราบ vs สำนักเขต ข้ามขั้นตอนกลั่นกรองจริงหรือไม่? → ไม่ข้าม**

5. **Use Case ID ที่หายไป (LAW020, 022, 029, 032, 033) → พบครบ ไม่ได้ตกหล่น**
   ทุกหมายเลขมีเนื้อหาจริงในเอกสาร แต่พบจุดที่ไดอะแกรมย่อรวมหลาย Use Case ไว้ในกล่องเดียวซึ่งควรแยกเพื่อความแม่นยำ (ยังไม่ได้แก้ในรอบนี้ — ผลกระทบต่ำ): (ก) LAW020 (กองกฎหมายแจ้งกอง/สำนัก) หายไปจากลำดับก่อน LAW021 ในหน้า 7.4 ส่วนชั้นต้น (ข) `p5_appeal_out` รวม LAW032 (กองบริหารคดีแจ้งกอง/สำนัก) + LAW033 (กอง/สำนักแจ้งผู้อุทธรณ์) + LAW034 (บันทึกผล) ไว้กล่องเดียว ทั้งที่ผู้กระทำเป็นคนละหน่วยงานกัน
6. **รายงาน 213 ใช้กับขั้นไต่สวนชี้มูลด้วยหรือไม่? → ไม่ใช่ ขั้นชี้มูลใช้รายงาน 644**
   213 = "รายงานการแสวงหาข้อเท็จจริง" เฉพาะขั้นไต่สวนเบื้องต้นเท่านั้น ขั้นไต่สวนชี้มูลใช้แบบฟอร์มคนละชุดเรียกว่ารายงาน 644 — เดิมหน้า 7.6 เขียนว่าขั้นชี้มูลใช้รายงาน 213 เช่นกัน เป็นความผิดพลาด **แก้ไขไดอะแกรมแล้ว** (`p7_n4`)
7. **แยก/รวมสำนวนต้องเข้าบอร์ดเสมอหรือไม่? → ขึ้นกับว่าออกเลขสำนวนไปแล้วหรือยัง**
   ถ้าพบซ้ำซ้อนตอนรับเรื่องร้องเรียน**ก่อน**ออกเลข PCMS เจ้าหน้าที่ศูนย์รับเรื่องรวมเรื่องเองได้ทันที ไม่ต้องรอมติบอร์ด ไม่ออกเลขใหม่ (Use Case CMP004/CMP014/CMP109) — แต่ถ้าเป็นสำนวนที่ออกเลขและอยู่ระหว่างไต่สวนแล้ว (กิจกรรมที่ 4 พบซ้ำภายหลัง หรือกิจกรรมที่ 5) ทั้งแยกและรวมสำนวนต้องผ่านมติบอร์ดเสมอ ไม่มีข้อยกเว้น **แก้ไขไดอะแกรมแล้ว** (`p7_n2`, `p7_n5`)
8. **"มติอื่นๆ" กับ "หนังสือทั่วไป" เป็นคำเดียวกันหรือไม่? → เป็นคนละหมวดกัน**
   "มติอื่นๆ" (RES018) คือผลการลงมติของบอร์ดในเรื่องนอกเหนือรับ/ไม่รับไต่สวน-ชี้มูล เช่น ตั้งคณะทำงานพิเศษ, ไม่อุทธรณ์/ไม่ฎีกา, เพิ่ม/กันผู้ถูกกล่าวหาเป็นพยาน — ต้องเข้าวาระบอร์ด "หนังสือทั่วไป" คืองานธุรการของกลุ่มงานกิจการฯ เช่น เบิกเบี้ยประชุม, บันทึกนำส่งมติ/คำสั่ง — **ไม่**เข้าวาระบอร์ด เดิมไดอะแกรมหน้า 7.6 ส่วนที่ 2 รวมทั้งสองสายเป็น flow เดียวผ่านบอร์ดทั้งหมด **แก้ไขไดอะแกรมแล้ว** (แยก Track A/B)
9. **คณะอนุกรรมการต่างๆ มีระดับเขตด้วยหรือไม่? → ไม่มี เฉพาะส่วนกลาง**
   คณะกลั่นกรอง 1-8 / สนับสนุนเลขาธิการฯ 2 / เปิดเผยข้อมูล / วินิจฉัยอุทธรณ์ เป็นชุดถาวรระดับส่วนกลางทั้งหมด สำนวนจากเขตต้องส่งเข้าส่วนกลางก่อนเสมอ ยกเว้นคณะอนุกรรมการไต่สวนที่ตั้งเฉพาะกิจรายคดีเท่านั้นที่ดึงคนจากเขตร่วมได้ — ไม่กระทบไดอะแกรมปัจจุบัน (ยังไม่เคยเขียนผิดจุดนี้)

## ⚠️ รายการคำถามที่ยัง "เปิดจริง" — ต้องยืนยันกับทีม/ผู้ใช้งานก่อนนำไปออกแบบ TO-BE

1. **กรณีพิเศษที่ยังไม่มี Requirement**: สำนวนเกี่ยวโยงกับคณะอนุกรรมการที่เคยพิจารณามาก่อน และกรณีอนุกรรมการมีส่วนได้เสียต้องถอนตัว — ยืนยันแล้วว่าไม่มีการกำหนดไว้ในเอกสารโครงการปัจจุบันเลย (ค้นซ้ำอีกรอบยังไม่พบ) ควรหยิบยกเป็นวาระถามในที่ประชุมเก็บ Requirement ครั้งถัดไป ไม่ใช่ปัญหาของไดอะแกรม

2. **ขอบเขตของ "หนังสือทั่วไป" ไม่ชัด 100%** — ไม่แน่ใจว่ารวม "หนังสือเชิญประชุม" ด้วยหรือไม่ แม้แต่ผู้ให้สัมภาษณ์เองก็ไม่มั่นใจในนิยาม ("พี่ไม่รู้ว่านิยามของคำว่าหนังสือทั่วไปคืออะไร") ควรยืนยันขอบเขตให้ชัดกับลูกค้าก่อนออกแบบฟังก์ชันแยกหมวดในระบบ — เพิ่ม note เตือนในไดอะแกรมแล้ว (`p8_ambig_note`)
