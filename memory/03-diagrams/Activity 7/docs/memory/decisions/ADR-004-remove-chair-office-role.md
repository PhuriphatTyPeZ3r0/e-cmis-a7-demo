# ⚖️ ADR-004: ตัด role `chair_office` (หน้าห้องประธานฯ) และสถานะ `PENDING_CHAIR_OF` ออกทั้งระบบ

## 📌 Context
Role `chair_office` (หน้าห้องประธานฯ — เจ้าหน้าที่คัดกรองก่อนเสนอประธานฯ) ไม่มีอยู่จริงในระบบแล้ว — `ROLES` ใน `assets/ecmis-app.js` ไม่มี role นี้มานานแล้ว (เหลือ 6 roles ตามคอมเมนต์ "Cleansed 6 Users") และ `getRole('chair_office')` มี fallback map ไปที่ `chairman` อยู่แล้ว แต่โค้ดส่วนอื่นยังค้าง STATUS/TRANSITIONS/UI ที่อ้างถึง role นี้เป็นสถานะกลาง (`PENDING_CHAIR_OF`) อยู่หลายจุด ทำให้มีปุ่ม/การ์ด/state ที่ไม่มีทางถูกเรียกใช้จริง (dead code) ปนอยู่กับของจริง

ตรวจสอบกับ พ.ร.บ.มาตรการของฝ่ายบริหารในการป้องกันและปราบปรามการทุจริต พ.ศ. 2551 (ถึงฉบับที่ 4 พ.ศ. 2568 — `law_pacc_68.pdf`) แล้วไม่พบมาตราใดที่ตั้งขั้นตอน "หน้าห้องประธานฯ คัดกรองก่อนเสนอประธานฯ" ไว้เป็นการเฉพาะ — ม.14 ให้อำนาจประธานฯ ออกคำสั่งเฉพาะ "ในที่ประชุม" เท่านั้น ไม่ครอบคลุมขั้นตอนก่อนเข้าสู่วาระ จึงไม่ใช่ role ที่มีฐานกฎหมายรองรับแยกจากประธานฯ

**เคยถูกทับกลับมาแล้วหนึ่งครั้ง:** รอบก่อนหน้านี้เคยลบออกจาก `assets/ecmis-app.js` ไปแล้ว แต่ถูก commit `feat(init)` (โดย Antigravity/E-CMIS Agent) เขียนทับไฟล์นี้ทั้งไฟล์ด้วยเวอร์ชันเก่าที่ยังมี role นี้อยู่ กลับมาโดยไม่มีใครตั้งใจ — เพราะไม่เคยมีการบันทึกการตัดสินใจนี้ไว้ใน memory vault เลย ADR นี้จึงมีไว้กันไม่ให้เกิดซ้ำเป็นครั้งที่สาม

## 🎯 Decision
1. **ตัด role และสถานะออกทั้งหมด:** ลบ `PENDING_CHAIR_OF` ออกจาก `STATUS`, `STATUS_CODE`, `STATUS_STEP`, `PAGE_FOR_MAIN`, `TRANSITIONS`, `pageForCaseByStatus()`, `getAct7Status()` ใน `assets/ecmis-app.js` — เส้นทางเดิมที่เคยผ่าน `PENDING_CHAIR_OF` (จาก `PENDING_SECGEN`/`IN_SUPPORT_SUB`/`PENDING_URGENT`) ให้ไปที่ `PENDING_CHAIRMAN` ตรงแทน
2. **คงไว้เฉพาะ backward-compat shim:** `getRole('chair_office')` ยัง fallback ไปที่ `chairman` เหมือนเดิม (รูปแบบเดียวกับ `board_ex`/`sup_chair`/`deputy_sg`) เผื่อ session/ลิงก์เก่าที่ยังเก็บ role id นี้ไว้
3. **ตัด dead UI ที่เกี่ยวข้องออกจากทุกหน้าที่มี:** `chairman-agenda.html`, `approval-review.html`, `inbox.html` (root) และคู่ `res/chairman.html`, `res/review.html`, `res/inbox.html` — ปุ่ม "นำเสนอประธานกรรมการ ป.ป.ท." (`toChair`) ที่ไม่มีทางถูกเรียก, การ์ด/ช่องกรอก "หมายเหตุจากหน้าห้องประธานฯ" ที่ไม่เคยถูกอ่านค่าไปใช้จริง, และคำว่า "หน้าห้องประธานฯ" ในข้อความ/ป้ายต่าง ๆ (เปลี่ยนเป็นอ้างถึง "ประธานกรรมการ ป.ป.ท." ตรง ๆ)
4. **หมายเหตุกฎหมาย:** ขั้นตอน "คำสั่งของประธานกรรมการ ป.ป.ท." (SCREEN/AGENDA/LEGAL/RETURN ใน `chairman.html`) เป็นขั้นตอนบริหารงานภายในตามระเบียบคณะกรรมการ ป.ป.ท. ไม่ใช่มาตราของ พ.ร.บ. โดยตรง — มีคอมเมนต์กำกับไว้ในโค้ดแล้ว อย่าอ้างอิงเป็นมาตราใน UI/เอกสารใด ๆ

**ผลกระทบต่อ AI ตัวอื่น:** ถ้าเจอโค้ดที่มี `chair_office`/`PENDING_CHAIR_OF` โผล่กลับมาอีก (เช่นจากการ merge/restructure/backup เก่า) ให้ถือว่าเป็นการทับกลับ ไม่ใช่ของใหม่ที่ต้องรักษาไว้ — ลบตาม ADR นี้ได้เลยโดยไม่ต้องถามซ้ำ
