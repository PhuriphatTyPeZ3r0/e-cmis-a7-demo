# ⚖️ ADR-002: การตัด 03-report-213 ออกจากขอบเขตของกิจกรรมที่ 7

## 📌 Context
ในอดีตมีการสร้างหน้า `03-report-213.html` ไว้ในโฟลเดอร์กิจกรรมที่ 7 แต่ตามขอบเขต TOR และกระบวนงานของระบบ E-CMIS การจัดทำรายงานผลการตรวจสอบข้อเท็จจริงตามมาตรา 213/644 เป็นหน้าที่ของ **กิจกรรมที่ 4 และ 5 (ชั้นรับเรื่องและไต่สวนเบื้องต้น)**

## 🎯 Decision
1. **Decommission:** ถอดหน้า `03-report-213.html` และ `res/report-213.html` ออกจากกิจกรรมที่ 7 ทั้งหมด
2. **Direct Routing:** ให้กระบวนงานในกิจกรรมที่ 7 เริ่มต้นรับสำนวนเข้าสู่ชั้นการเสนอความเห็นและกลั่นกรองสำนวนที่ `review.html` (Approval Review) ทันที
