- [x] ระบุ **การกระทำ (action)** ที่ทำในขั้นนั้น
- [x] แยกสี ภายใน ป.ป.ท. (เขียว) / ภายนอก (เหลือง) / นอกขอบเขต (เทาเส้นประ)
- [x] มีจุดเริ่มต้น (●) และจุดสิ้นสุด (◉) ครบทุกเส้นทาง

- [ ] **[รอเติม]** กรอบระยะเวลา (SLA) รายขั้นตอน เช่น 60 วัน, 15 วันทำการ, 2 ปี (ใส่บางจุดแล้ว ยังไม่ครบทุกกล่อง)

### 3.2 กระบวนงานหลักที่ต้องมี — หน้า 7.1 ไต่สวนเบื้องต้น
- [x] เสนอรายงานตามสายบังคับบัญชา (5 ตำแหน่ง)
- [x] จุดตัดสินใจ: เลขาธิการ — ซับซ้อน? (แยกอนุสนับสนุน 2 คณะ)
- [x] หน้าห้องประธาน คัดกรอง
- [x] จุดตัดสินใจ: ประธาน — เร่งด่วน/ผ่านอนุสนับสนุน? (ข้ามกลั่นกรอง)
- [x] กองบริหารคดี (กบค.) กระจายสำนวน → อนุกลั่นกรอง (คณะ 1-8)

- [x] เสนอรายงานตามสายบังคับบัญชา → เลขาธิการลงนาม → อนุกลั่นกรอง → จัดวาระ
- [x] บอร์ดพิจารณาวินิจฉัยชี้มูล
- [x] มติ 4 ทาง: ส่ง ป.ป.ช. / ไต่สวนเพิ่ม (loop) / ยุติเรื่อง(+ส่งหน่วยงาน) / ชี้มูล
- [x] ชี้มูล → กองบริหารคดี (กบค.) จัดทำรายงาน → บอร์ด/ประธานลงนาม → ส่งคืนกอง/สำนักงาน ป.ป.ท. เขต ที่รับผิดชอบ
- [x] ยุติเรื่อง/ส่งหน่วยงาน → กองบริหารคดี (กลุ่มงานคำวินิจฉัยและมติคณะกรรมการ) จัดทำรายงานมติและส่งเอกสารคืนกอง/สำนักงาน ป.ป.ท. เขต ที่รับผิดชอบ → กอง/สำนักงาน ป.ป.ท. เขต ที่รับผิดชอบบันทึกรับมติในระบบ และดำเนินการแจ้งผลการพิจารณาไปยังผู้ถูกกล่าวหา (ไม่ช้ากว่า 15 วันนับแต่วันที่มีมติ) / ส่งหน่วยงานที่เกี่ยวข้อง / รายงาน ป.ป.ช. → เปลี่ยนสถานะเป็น "ปิดคดี" (Closed)
- [x] แยกสายอาญา (→ พนักงานอัยการ, กจ.10) และสายวินัย (→ ต้นสังกัด, กจ.8)

### 3.4 ประเด็นที่ควรตรวจสอบ/ยืนยันเพิ่มเติมกับเจ้าหน้าที่ (ยังไม่ครบ 100%)
- [ ] **ผู้ลงนามคำสั่งแต่งตั้งคณะไต่สวน (7.1)** — เอกสารมีทั้ง "คำสั่งคณะกรรมการ ป.ป.ท." และ "คำสั่งสำนักงาน ป.ป.ท." (คำสั่ง 2 แบบ) — ควรระบุให้ชัดว่าใช้แบบใดเมื่อใด
- [ ] **จำนวนสำเนารายงาน** สำหรับกรรมการ (7-11 ชุด ตาม AS-IS) — เป็น Pain point ที่ TO-BE ต้องแก้ ยังไม่แสดงในผัง
- [ ] **การนับ SLA ทางวินัย** — 60 วันหลังรับหนังสือ, รายงานกลับใน 30 วัน, แจ้งเตือนเกิน 90 วัน (จากบันทึกประชุม) ยังไม่แสดงในผัง 7.2
- [ ] **กรณีอัยการไม่สั่งฟ้อง / ความเห็นแย้ง** — วนกลับเข้าบอร์ด กจ.7 (มีใน Activity 10 แล้ว) — ควรตรวจว่า 7.2 ต้องแสดง entry point นี้หรือไม่
- [ ] **เงื่อนไขเวลา 2 ปี (ขยายรวมไม่เกิน 3 ปี)** ของชั้นไต่สวน — อยู่ในระบบไต่สวน (นอกขอบเขต 7) แต่ควร cross-check กับ 7.2

## ส่วนที่ 5: คำถามและประเด็นที่ยังขาดข้อมูล (TOR Gaps & Questions)

เพื่อนำมาประกอบการออกแบบระบบและ Flowchart ในระดับรายละเอียด (Detailed Design) ให้ครบถ้วนตาม TOR จำเป็นต้องสอบถามหรือตรวจสอบประเด็นเหล่านี้เพิ่มเติมกับหน่วยงาน:

1. **กระบวนการ "ดึงเรื่องกลับ / ส่งคืนเรื่อง" (Recall / Return Workflow - TOR 7.2.1.2, 7.2.2.4, 7.2.3.5):**
   * *คำถาม:* เงื่อนไขในการดึงเรื่องกลับ (Recall) หรือส่งเรื่องคืน (Return) มีหลักเกณฑ์อย่างไร? (เช่น สามารถดึงเรื่องกลับได้เฉพาะเมื่อสถานะสำนวนยังไม่ผ่านการอนุมัติขั้นสุดท้ายใช่หรือไม่? และเมื่อดึงเรื่องกลับแล้ว สำนวนจะย้อนกลับไปค้างที่สถานะใด?)
2. **การตรวจสอบความซ้ำซ้อนสำนวนคดีเสนอบรรจุวาระ (De-duplication - TOR 7.1.3.8):**
   * *คำถาม:* ระบบต้องตรวจสอบความซ้ำซ้อนของสำนวนโดยใช้ข้อมูลใดเป็นหลักเกณฑ์? (เช่น เลขบัตรประจำตัวประชาชนผู้ถูกกล่าวหา + ลักษณะข้อกล่าวหาที่ตรงกัน หรือรหัสสำนวนจาก ป.ป.ช.?) และขั้นตอนตรวจสอบนี้ต้องดำเนินการโดยเจ้าหน้าที่กองบริหารคดี (กบค.) หรือระบบทำการแจ้งเตือนโดยอัตโนมัติเมื่อจัดวาระ?
3. **การส่งมติของคณะอนุกรรมการกลั่นกรองฯ กลับหน่วยงาน (TOR 7.1.3.4):**
   * *คำถาม:* มติของคณะอนุกรรมการกลั่นกรองฯ (ก่อนเข้าที่ประชุมบอร์ดใหญ่) เมื่อพิจารณาแล้ว ต้องจัดทำหนังสือแจ้งเตือนไปยังหน่วยงานภายในใดบ้าง? (เช่น ส่งกลับไปยังกอง หรือสำนักงาน ป.ป.ท. เขต เจ้าของสำนวนเดิมเพื่อทราบความเห็นและเตรียมการ หรือต้องทำหนังสือจัดส่งหน่วยงานภายนอกด้วยหรือไม่?)
4. **ความสามารถในการปรับแต่งหน้าหนังสือจัดวาระและคำสั่ง (Template Customization - TOR 7.1.3.6, 7.2.2.3):**
   * *คำถาม:* ขอบเขตคำว่า "สร้างรูปแบบหนังสือ/คำสั่งเองได้" ระบบต้องการให้อัปโหลดไฟล์ Word ต้นแบบ (Mail Merge Template) เข้าไปในระบบเพื่อดึงฟิลด์อัตโนมัติ หรือออกแบบลักษณะ Visual Builder ผ่านระบบ CMS?
5. **เกณฑ์การตั้งเงื่อนไขเวลาและระบบแจ้งเตือน (SLA & Notifications - TOR 7.2.1.3, 7.2.2.2, 7.2.3.2):**
   * *คำถาม:* กรอบเวลาของการจัดทำคำสั่ง/รายงานชี้มูล/หนังสือลงวินัยที่ต้องมีระบบแจ้งเตือน มีข้อกำหนดตามระเบียบกฎหมายภายในกี่วันทำการหลังจากบอร์ดมีมติ? (เช่น ต้องออกคำสั่งใน 15 วันทำการ และแจ้งเตือนผู้รับผิดชอบกี่วันก่อนครบกำหนด?)
