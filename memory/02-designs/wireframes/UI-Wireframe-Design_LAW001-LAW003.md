# E-CMIS — UI Layout & Wireframe Specification
## กิจกรรมที่ 10: ระบบบริหารจัดการกระบวนการด้านกฎหมายในทางคดี (LAW001–LAW003)

| รายการ | รายละเอียด |
|:---|:---|
| โครงการ | ระบบบริหารจัดการและติดตามสำนวนคดีทุจริตและประพฤติมิชอบในภาครัฐ (E-CMIS) ครั้งที่ 2 |
| หน่วยงาน | สำนักงาน ป.ป.ท. (PACC) — กองกฎหมาย |
| ผู้จัดทำ | SS CONSORTIUM — ทีม UX/UI & System Analyst |
| อ้างอิง | Design System v1.1 (`ecmis.css`), เล่ม 8 กิจกรรมที่ 10 (BRD LAW001–LAW003) |
| Design Principles | Density earns trust · Every state is visible · Thai language first · Predictable over surprising |

**Design Tokens ที่ใช้ทั้งเอกสาร:** Font `Sarabun` / Sidebar `--navy-deep #0D1B3E` กว้าง `260px` / Topbar สูง `64px` / พื้นหลัง `--off-white #F0F4FA` / Component หลัก: `ecmis-card`, `ecmis-table`, `status-badge (green|orange|red|teal)`, `btn-navy`, `btn-gold`, `btn-outline-navy`

**Global Layout (ใช้ร่วมทุกหน้าจอ):**
- **Sidebar (ซ้าย, `--navy-deep`):** โลโก้ ป.ป.ท. + "E-CMIS" ด้านบน, เมนูกลุ่ม "งานกฎหมายในทางคดี" ประกอบด้วย 4 เมนูย่อย (สำนวนคดีชั้นอัยการ/ศาล, คำร้องขอเปิดเผยข้อมูล, อุทธรณ์คำสั่งไม่เปิดเผย, คดีปกครอง) — active state ขีดทอง `--gold` ด้านซ้าย
- **Topbar (บน, สูง 64px):** Hamburger toggle · Page Title (Sarabun 600) · Global Search · ไอคอนกระดิ่งแจ้งเตือน (Badge แดงแสดงจำนวนเรื่องใกล้ครบกำหนด) · User Dropdown แสดงชื่อ-บทบาท (RBAC)
- **Main Content Area:** พื้นหลัง `--off-white`, ลำดับ Breadcrumb → Summary Cards → Filters → Data Table → Modal (overlay)

# หน้าจอที่ 1: ระบบบริหารจัดการสำนวนคดีชั้นอัยการและชั้นศาล (LAW001)

## 1.1 Screen Title
**"สารบบสำนวนคดีชั้นอัยการและชั้นศาล"** — LAW001 Case Registry & Tracking

## 1.2 Objective
- **วัตถุประสงค์:** จุดเดียวสำหรับรับเรื่อง–มอบหมาย–ติดตามสถานะ–บันทึกคำพิพากษา–จัดทำสารบบ ของสำนวนคดีในชั้นอัยการและชั้นศาล (LAW001.01–.10) แก้ปัญหา AS-IS ที่ติดตามคดีข้ามชั้นด้วยทะเบียนกระดาษ/Excel และพลาดกำหนดอายุความ
- **ผู้ใช้เป้าหมาย:** นิติกร (บันทึก/ติดตาม), หัวหน้ากลุ่มงานคดี (มอบหมาย), ผู้บริหารกองกฎหมาย (ดูภาพรวม/รายงาน)

## 1.3 UI Layout & Structure
```
┌ Topbar: "สารบบสำนวนคดีชั้นอัยการและชั้นศาล" · 🔔(3) · User ┐
├─Sidebar─┬──────────────────────────────────────────────────┤
│ (Navy)  │ Breadcrumb: งานกฎหมาย > สำนวนคดีชั้นอัยการ/ศาล     │
│ ▸LAW001●│ [Summary Cards ×4]                                │
│ ▸LAW002 │ [Filters & Search Bar]          [+ รับสำนวนใหม่]   │
│ ▸อุทธรณ์ │ [Data Table — high density, sticky header]        │
│ ▸LAW003 │ [Pagination · แสดง 25/50/100 รายการ]              │
└─────────┴──────────────────────────────────────────────────┘
```

## 1.4 Key Sections & Components

### A) Summary Cards (แถวบน — `ecmis-card` ขนาดเล็ก 4 ใบ)
| Card | ตัวเลข | Accent |
|:---|:---|:---|
| สำนวนทั้งหมด | 248 | เส้นบน `--navy` |
| อยู่ระหว่างชั้นอัยการ | 96 | `--teal` |
| อยู่ระหว่างชั้นศาล | 117 | `--orange` |
| **ใกล้ครบกำหนด/อายุความ ≤ 30 วัน** | **12** | `--red` + ไอคอนนาฬิกา, คลิกแล้ว filter ตารางทันที (LAW001.05) |

### B) Filters & Search (Input Controls — แถวเดียว ใน `ecmis-card`)
- **Text Field:** ค้นหา เลขสำนวน ป.ป.ท. / คดีดำ–แดง / ชื่อผู้กล่าวหา–ผู้ถูกกล่าวหา (placeholder: "เลขสำนวน, คดีดำ-แดง, ชื่อบุคคล…")
- **Dropdown — ประเภทสำนวน (6 ประเภท ตาม TOR ๑๐.๑.๑.๑):** ไม่ฟ้อง / ถอนฟ้อง / ไม่อุทธรณ์ / ถอนอุทธรณ์ / ไม่ฎีกา / ถอนฎีกา (LAW001.01)
- **Dropdown — ชั้นการดำเนินการ:** ชั้นอัยการ / ศาลชั้นต้น / ศาลอุทธรณ์ / ศาลฎีกา / คดีถึงที่สุด
- **Dropdown — สำนักงานอัยการ/ศาล** และ **Dropdown — ผู้รับผิดชอบสำนวน**
- **Date Range Picker:** วันที่รับเรื่อง (พ.ศ.)
- ปุ่ม `btn-navy` "ค้นหา" · `btn-outline-navy` "ล้างเงื่อนไข" · ขวาสุด `btn-gold` "**+ รับสำนวนใหม่**"

### C) Data Table (List Table Pattern — `ecmis-table` ความหนาแน่นสูง)
| คอลัมน์ | หมายเหตุ |
|:---|:---|
| เลขสำนวน ป.ป.ท. | `<strong>` ลิงก์เปิด Modal รายละเอียด |
| ประเภทสำนวน | ไม่ฟ้อง/ถอนฟ้อง/ไม่อุทธรณ์/ถอนอุทธรณ์/ไม่ฎีกา/ถอนฎีกา |
| ผู้กล่าวหา → ผู้ถูกกล่าวหา | 2 บรรทัดในเซลล์เดียว (density) |
| คดีดำ / คดีแดง | เช่น อท 112/2568 · แสดง "–" หากยังไม่มีเลขแดง |
| อัยการ/ศาลที่รับผิดชอบ | |
| ผู้รับผิดชอบสำนวน | Avatar ย่อ + ชื่อนิติกร |
| สถานะ | `status-badge`: 🟢 green "คดีถึงที่สุด" · 🟠 orange "อยู่ระหว่างพิจารณาศาลชั้นต้น" · 🔵 teal "รอคำวินิจฉัยอัยการ" · 🔴 red "ใกล้ครบอายุความ 15 วัน" |
| ครบกำหนด/อายุความ | วันที่ + countdown; แดงเมื่อ ≤ 30 วัน (Every state is visible) |
| จัดการ | `btn-outline-navy btn-sm` "ดูรายละเอียด" · `btn-navy btn-sm` "บันทึกสถานะ" |

### D) Detail & Action Modals (Forms)
**Modal 1 — รับเรื่อง/รายละเอียดสำนวน (LAW001.01):** ฟอร์ม 2 คอลัมน์ใน `ecmis-card`: Text Field เลขสำนวน ป.ป.ท. (auto-suggest ดึงจากระบบไต่สวน — Single Data Input ไม่คีย์ซ้ำ), Dropdown ประเภทสำนวน, Text Field ผู้กล่าวหา/ผู้ถูกกล่าวหา (เพิ่มได้หลายราย), Text Field คดีดำ–คดีแดง, Dropdown สำนักงานอัยการ/ศาล, Date Picker วันครบอายุความ (ระบบคำนวณแจ้งเตือนอัตโนมัติ) · Footer: `btn-navy` "บันทึก" / `btn-outline-navy` "ยกเลิก"

**Modal 2 — มอบหมายผู้รับผิดชอบ (LAW001.02):** Dropdown เลือกนิติกร (แสดงจำนวนสำนวนในมือ), Date Picker วันที่มอบหมาย, Textarea ขอบเขตงาน · `btn-gold` "มอบหมาย" (ระบบส่ง Notification + บันทึก Audit Trail)

**Modal 3 — บันทึกสถานะ/คำพิพากษา (LAW001.03, .04, .06):** Tab 3 แถบ: ① สถานะการดำเนินการ (Dropdown + Timeline ประวัติ) ② คำพิพากษา — Dropdown ชั้นศาล (ชั้นต้น/อุทธรณ์/ฎีกา), Dropdown ผลคำพิพากษา, Textarea สรุปย่อ, **File Upload** Word/Excel/PDF (LAW001.09) ③ มติคณะกรรมการ ป.ป.ท. — Text Field ครั้งที่ประชุม, Date Picker, Textarea มติ · `btn-navy` "บันทึก"

**Modal 4 — แจ้งผลการดำเนินคดีให้หน่วยงานภายใน (TOR ๑๐.๑.๙ / LAW001.08):** Multi-select Checkbox หน่วยงานภายใน (กองบริหารคดี, กอง/สำนักเจ้าของสำนวน ฯลฯ), Dropdown Template หนังสือแจ้งผลตามแบบสำนักงาน ป.ป.ท., Preview เอกสาร · `btn-gold` "ส่งแจ้งผล" พร้อมบันทึกหลักฐานการแจ้งใน Audit Trail

**Drawer — สารบบ/ประวัติสำนวน (LAW001.09):** เลื่อนจากขวา แสดง Timeline แนวตั้งทุกเหตุการณ์ (รับเรื่อง→มอบหมาย→คำวินิจฉัยอัยการ→คำพิพากษาแต่ละชั้น→มติบอร์ด) + ปุ่ม Export Word/Excel/PDF (`btn-outline-navy`)

# หน้าจอที่ 2: ระบบพิจารณาคำร้องขอเปิดเผยข้อมูลข่าวสาร (LAW002 — ส่วนคำร้อง)

## 2.1 Screen Title
**"ทะเบียนคำร้องขอเปิดเผยข้อมูลข่าวสาร"** — LAW002 Information Disclosure Requests

## 2.2 Objective
- **วัตถุประสงค์:** บริหารคำร้องขอข้อมูลข่าวสารตั้งแต่รับเรื่อง–ติดตามสถานะ–บันทึกผลคณะอนุกรรมการ–แจ้งผลหน่วยงาน–จัดทำสารบบ (LAW002.01–.07) โดยมีนาฬิกากำกับระยะเวลาตามกฎหมายข้อมูลข่าวสารทุกรายการ
- **ผู้ใช้เป้าหมาย:** เจ้าหน้าที่รับเรื่อง (บันทึก), นิติกร (พิจารณา/เสนอ), ผู้บริหาร (อนุมัติ/ดูสถิติ)

## 2.3 UI Layout & Structure
Layout มาตรฐานเดียวกับหน้าจอที่ 1 (Predictable over surprising) — จุดต่างคือ **แถบ Tab บนสุดของ Main Content**: `[ คำร้องขอข้อมูล ]  [ คำอุทธรณ์คำสั่งไม่เปิดเผย ]` (Tab ที่ 2 คือหน้าจอที่ 3) — Tab active ขีดล่าง `--gold`

## 2.4 Key Sections & Components

### A) Summary Cards (×4)
| Card | Accent |
|:---|:---|
| คำร้องทั้งหมด (ปีงบประมาณ) | `--navy` |
| อยู่ระหว่างพิจารณา | `--orange` |
| **ครบกำหนดภายใน 7 วัน** (LAW002.04) | `--red` — คลิกเพื่อ filter |
| แจ้งผลแล้ว | `--green` |

### B) Filters & Search
- **Text Field:** เลขที่คำร้อง / ชื่อผู้ร้อง
- **Dropdown — ประเภทเรื่อง:** คำร้องขอข้อมูล / คำอุทธรณ์ (LAW002.01)
- **Dropdown — สถานะ:** รับเรื่อง / เสนอคณะอนุกรรมการ / รอมติ / แจ้งผลแล้ว
- **Dropdown — หน่วยงาน ป.ป.ท. ที่เสนอเรื่อง**
- **Date Range:** วันที่รับคำร้อง · ปุ่ม `btn-navy` "ค้นหา" · `btn-gold` "**+ รับคำร้องใหม่**"

### C) Data Table
| คอลัมน์ | หมายเหตุ |
|:---|:---|
| เลขที่คำร้อง | ลิงก์เปิด Modal |
| ประเภทเรื่อง | Badge `teal` "คำร้องขอข้อมูล" |
| ชื่อผู้ร้อง | |
| หน่วยงานที่เสนอเรื่อง | |
| วันที่รับ | พ.ศ. |
| **กำหนดแล้วเสร็จ (ตามกฎหมาย)** | countdown เช่น "เหลือ 5 วัน" — สีตามระดับ: ปกติ/`--orange` ≤ 15 วัน/`--red` ≤ 7 วัน |
| ผลคณะอนุกรรมการ | เปิดเผย / ไม่เปิดเผย / เปิดเผยบางส่วน / "–" |
| สถานะ | `status-badge`: 🔵 teal "รอเสนอคณะอนุกรรมการ" · 🟠 orange "อยู่ระหว่างพิจารณา" · 🟢 green "แจ้งผลแล้ว" · 🔴 red "เกินกำหนด 2 วัน" |
| จัดการ | "ดูรายละเอียด" · `btn-navy btn-sm` "บันทึกผล" |

### D) Detail & Action Modals
**Modal 1 — รับคำร้อง (LAW002.01):** Dropdown ประเภทเรื่อง, Text Field ชื่อผู้ร้อง, Dropdown หน่วยงาน ป.ป.ท. ที่เสนอ, Date Picker วันที่รับ, Number Field ระยะเวลาดำเนินการ (วัน — ระบบคำนวณวันครบกำหนดและตั้งการแจ้งเตือนอัตโนมัติ), Textarea รายละเอียดข้อมูลที่ขอ · `btn-navy` "บันทึกรับเรื่อง"

**Modal 2 — บันทึกผลการพิจารณา (LAW002.03, .05):** Section แรก "คณะอนุกรรมการฯ" — Date Picker วันประชุม, Dropdown ผลการพิจารณา (เปิดเผย/ไม่เปิดเผย/เปิดเผยบางส่วน), Textarea เหตุผล, File Upload มติ · Section สอง "เลขาธิการ/คณะกรรมการ ป.ป.ท." — โครงเดียวกัน · `btn-navy` "บันทึก"

**Modal 3 — แจ้งผลหน่วยงานที่เกี่ยวข้อง (LAW002.06):** Multi-select Checkbox หน่วยงานภายใน, Dropdown รูปแบบหนังสือแจ้ง (Template ตามที่ สนง. กำหนด), Preview เอกสาร · `btn-gold` "ส่งแจ้งผล" (บันทึกหลักฐานการแจ้ง + Audit Trail)

# หน้าจอที่ 3: ระบบพิจารณาอุทธรณ์คำสั่งไม่เปิดเผยข้อมูลข่าวสาร (LAW002 — ส่วนอุทธรณ์)

## 3.1 Screen Title
**"ทะเบียนคำอุทธรณ์คำสั่งไม่อนุญาตให้เปิดเผยข้อมูลข่าวสาร"** — LAW002 Appeals Registry

## 3.2 Objective
- **วัตถุประสงค์:** จัดการคำอุทธรณ์คำสั่งไม่เปิดเผยข้อมูล บันทึกผลการพิจารณาของเลขาธิการและคณะกรรมการ ป.ป.ท. พร้อมฐานข้อมูลคำอุทธรณ์ที่เก็บไฟล์ Word/Excel/PDF และสืบค้นได้หลายเงื่อนไข (LAW002.05–.07)
- **ผู้ใช้เป้าหมาย:** นิติกรผู้รับผิดชอบสำนวนอุทธรณ์, เลขานุการคณะกรรมการ, ผู้บริหาร

## 3.3 UI Layout & Structure
เข้าถึงผ่าน **Tab ที่ 2** ของหน้าจอ LAW002 (โครงสร้างเดียวกัน ลด learning curve) — จุดเด่นเฉพาะหน้านี้คือ **Advanced Search Panel** (ยุบ/ขยายได้) เหนือตาราง รองรับการสืบค้นฐานข้อมูลคำอุทธรณ์ตามเงื่อนไขต่าง ๆ ตาม LAW002.07

## 3.4 Key Sections & Components

### A) Summary Cards (×4)
คำอุทธรณ์ทั้งหมด (`--navy`) · รอเลขาธิการพิจารณา (`--teal`) · รอคณะกรรมการ ป.ป.ท. (`--orange`) · **ครบกำหนดพิจารณา ≤ 7 วัน** (`--red`)

### B) Filters & Search (Advanced Search — `ecmis-card` ยุบ/ขยาย)
- แถวหลัก: Text Field เลขที่อุทธรณ์/ชื่อผู้อุทธรณ์ · Dropdown สถานะ · Date Range วันที่รับ
- แถว Advanced (ขยาย): Dropdown ผลการพิจารณา (ยืนตามคำสั่งเดิม/ให้เปิดเผย/เปิดเผยบางส่วน), Dropdown ชั้นการพิจารณา (เลขาธิการ/คณะกรรมการ), Text Field คำค้นในเอกสารแนบ (Full-text search ในไฟล์สารบบ), Dropdown หน่วยงานเจ้าของคำสั่งเดิม
- `btn-navy` "ค้นหา" · `btn-outline-navy` "ล้างเงื่อนไข" · `btn-gold` "**+ รับคำอุทธรณ์ใหม่**"

### C) Data Table
| คอลัมน์ | หมายเหตุ |
|:---|:---|
| เลขที่อุทธรณ์ | ลิงก์ |
| ชื่อผู้อุทธรณ์ | |
| อ้างอิงคำร้องเดิม | ลิงก์ข้ามไป Tab คำร้อง (ข้อมูลเชื่อมโยง ไม่คีย์ซ้ำ) |
| วันที่รับอุทธรณ์ / ครบกำหนด | countdown |
| ผลเลขาธิการ | Badge หรือ "–" |
| ผลคณะกรรมการ ป.ป.ท. | Badge หรือ "–" |

### D) Detail & Action Modals
**Modal 1 — รับคำอุทธรณ์:** Text Field ชื่อผู้อุทธรณ์, Auto-suggest เลือกคำร้อง/คำสั่งเดิมจากทะเบียน (ดึงข้อมูลเดิมมาแสดงอัตโนมัติ), Date Picker วันที่รับ, Textarea เหตุผลการอุทธรณ์, **File Upload** คำอุทธรณ์ (Word/Excel/PDF, ลากวางได้, แสดงขนาด/ชนิดไฟล์) · `btn-navy` "บันทึก"

**Modal 2 — บันทึกผลการพิจารณา (LAW002.05):** Stepper 2 ขั้น: ① เลขาธิการ ป.ป.ท. — Dropdown ผล, Date Picker, Textarea ความเห็น, File Upload ② คณะกรรมการ ป.ป.ท. — Text Field ครั้งที่ประชุม, Dropdown มติ, File Upload มติที่ประชุม · แสดงสถานะแต่ละขั้นด้วย `badge-dot` · `btn-navy` "บันทึก" / `btn-gold` "บันทึกและแจ้งผล"

# หน้าจอที่ 4: ระบบการจัดการและควบคุมงานคดีปกครอง (LAW003)

## 4.1 Screen Title
**"สารบบคดีปกครอง"** — LAW003 Administrative Case Control

## 4.2 Objective
- **วัตถุประสงค์:** ควบคุมคดีปกครองที่ ป.ป.ท. เป็นคู่กรณี ตั้งแต่รับหมายเรียก/คำสั่งศาล–มอบหมายนิติกร–ติดตามสถานะ–บันทึกผลคำพิพากษา (แพ้/ชนะ) จนจัดทำสารบบสำนวน (LAW003.01–.05) พร้อมค้นหามูลเหตุแห่งการฟ้องจากสารบบคดีของ ป.ป.ท. โดยตรง
- **ผู้ใช้เป้าหมาย:** นิติกรกลุ่มงานคดีปกครอง, หัวหน้ากลุ่มงาน (มอบหมาย), ผู้บริหารกองกฎหมาย

## 4.3 UI Layout & Structure
Layout มาตรฐาน — จุดเด่นเฉพาะ: คอลัมน์ **ผลคดี (แพ้/ชนะ)** ที่มองเห็นทันทีในตาราง และปุ่มค้นหามูลเหตุจากสารบบคดี ป.ป.ท. ในฟอร์มรับเรื่อง (Integration ภายในระบบ E-CMIS)

## 4.4 Key Sections & Components

### A) Summary Cards (×4)
คดีปกครองทั้งหมด (`--navy`) · อยู่ระหว่างพิจารณาชั้นต้น (`--orange`) · อยู่ระหว่างพิจารณาชั้นสูงสุด (`--teal`) · **นัดหมาย/ครบกำหนดสัปดาห์นี้** (`--red`) — แถวที่สองเสริม Mini-stat: ชนะคดี 68% | แพ้ 22% | จำหน่าย 10% (แถบสัดส่วนสี green/red/silver)

### B) Filters & Search
- **Text Field:** คดีดำ–แดง / ชื่อผู้ฟ้อง–ผู้ถูกฟ้อง–ผู้ร้องสอด
- **Dropdown — ศาล:** ศาลปกครองกลาง / ภูมิภาค / ศาลปกครองสูงสุด
- **Dropdown — ประเภทคดี:** ชั้นต้น / สูงสุด (LAW003.01)
- **Dropdown — สถานะทางคดี:** อยู่ระหว่างพิจารณา / คดีถึงที่สุด / จำหน่ายคดี (LAW003.04)
- **Dropdown — นิติกรผู้รับผิดชอบ** · **Dropdown — ปีงบประมาณ (TOR ๑๐.๓.๑.๒)** · Date Range วันที่รับหมาย
- `btn-navy` "ค้นหา" · `btn-gold` "**+ รับหมายเรียก/คำสั่งศาล**"

### C) Data Table
| คอลัมน์ | หมายเหตุ |
|:---|:---|
| คดีดำ / คดีแดง | `<strong>` ลิงก์ |
| ศาล | ชื่อศาลปกครอง |
| ประเภท | Badge `teal` "ชั้นต้น" / navy "สูงสุด" |
| ผู้ฟ้อง / ผู้ถูกฟ้อง / ผู้ร้องสอด | 2–3 บรรทัดในเซลล์ (density) |
| มูลเหตุแห่งการฟ้อง | ลิงก์ไปสำนวนต้นเรื่องในสารบบ ป.ป.ท. |
| นิติกรผู้รับผิดชอบ | Avatar + ชื่อ |
| สถานะดำเนินการ | 🔵 teal "เสนอบอร์ด ป.ป.ท. มอบอำนาจ" · 🟠 orange "อยู่ระหว่างกลุ่มงานคดี" · 🟢 green "ส่งสำนวนให้อัยการแล้ว" (LAW003.03) |
| ผลคดี | Badge `green` "ชนะคดี" / `red` "แพ้คดี" / silver "จำหน่ายคดี" / "–" |
| นัดหมาย/กำหนดถัดไป | วันที่ + countdown, แดงเมื่อ ≤ 7 วัน |
| จัดการ | "ดูรายละเอียด" · `btn-navy btn-sm` "บันทึกผล" |

### D) Detail & Action Modals
**Modal 1 — รับหมายเรียก/คำสั่งศาล (LAW003.01):** Dropdown ชื่อศาล, Dropdown ประเภทคดี (ชั้นต้น/สูงสุด), Text Field คดีดำ–คดีแดง, Text Field ผู้ฟ้อง/ผู้ถูกฟ้อง/ผู้ร้องสอด (repeatable rows), Dropdown ปีงบประมาณที่รับเรื่อง (TOR ๑๐.๓.๑.๒), **Search Field "ค้นหามูลเหตุแห่งการฟ้อง"** — พิมพ์แล้วค้นสารบบคดี ป.ป.ท. แสดงผลเป็นรายการเลือกผูกความเชื่อมโยง (ลดการคีย์ซ้ำ ตาม Single Data Input), File Upload หมายเรียก/คำสั่ง · `btn-navy` "บันทึกรับเรื่อง"

**Modal 2 — มอบหมายนิติกร (LAW003.02):** Dropdown นิติกร (แสดง workload), Date Picker วันที่มอบหมาย, Textarea ขอบเขตงาน · `btn-gold` "มอบหมาย" + Notification อัตโนมัติ

**Modal 3 — บันทึกสถานะดำเนินการ (LAW003.03):** Radio/Dropdown สถานะ: เสนอคณะกรรมการ ป.ป.ท. มอบอำนาจ / อยู่ระหว่างกลุ่มงานคดี / จัดส่งสำนวนให้พนักงานอัยการ (เลือกข้อนี้จะเปิด **File Upload หนังสือนำส่ง** — required) / อื่น ๆ (Text Field ระบุ) · Timeline ประวัติสถานะด้านล่าง · `btn-navy` "บันทึก"

**Modal 4 — บันทึกผลคำพิพากษา (LAW003.04–.05):** Dropdown สถานะทางคดี (อยู่ระหว่างพิจารณาชั้นต้น/สูงสุด/คดีถึงที่สุด/จำหน่ายคดี), Dropdown ผลคดี (**ชนะคดี / แพ้คดี**), Date Picker วันที่มีคำพิพากษา, Textarea สรุปคำพิพากษา, **File Upload** คำพิพากษา Word/Excel/PDF (multi-file) · หากเลือก "แพ้คดี" แสดง Alert แถบ `--orange` "โปรดพิจารณาสิทธิอุทธรณ์ภายในกำหนด" พร้อม Date Picker กำหนดอุทธรณ์ (ตั้งแจ้งเตือนอัตโนมัติ) · `btn-navy` "บันทึกผลคดี"
