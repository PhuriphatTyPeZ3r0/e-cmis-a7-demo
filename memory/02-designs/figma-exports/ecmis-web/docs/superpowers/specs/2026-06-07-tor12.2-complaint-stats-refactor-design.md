## A3. ชั้น Data

### Dimension/enum
```csharp
enum LegalType  { M18_4_2, M62, M58_2, M18_1Ka, Other }
enum Channel    { /* 17 ช่อง — ดู Appendix 1.3 */ }
enum Zone       { Kpt1..Kpt5, Pt1..Pt9, Kot }   // กปท.1–5 + ปปท.1–9 + กอท.

```

### StatRecord (synthetic)
```csharp
record StatRecord(int Year, DateTime ReceivedAt, LegalType Type,
                  Channel Channel, Zone Zone, string Province, CaseStatus Status);
```

กลยุทธ์ปั้น (ปี 2569 = 560 rows):
- ปั้นเฉพาะ 2569 (เดือน ต.ค.68=250, พ.ย.68=310) — ปีเก่าใช้ `YearlyTotals` constant
- deterministic (seed คงที่)
- honor joint **เดือน×มาตรา** เป๊ะ; มิติเดี่ยว (เขต/ช่องทาง/จังหวัด/สถานะ) แจก largest-remainder ให้ยอดรวมตรงเป๊ะ
- cross-tab ข้ามมิติ = ค่าประมาณ (ยอมรับแล้ว)

### reconcile (จากเล่มจริง)
มี 2 มุมมองของ "มาตรา" ที่ตัวเลขต่างกันเล็กน้อย — เก็บแยกเป็น 2 constant:
- **มุมรับเข้า (เดือน×section):** ม.62/พรบ=166, ม.18/4=393, +ออกเลขเพิ่ม=1 → 560
- **มุมประเภทกฎหมาย (donut):** ม.62/18/1(ข)=163, ม.18/4(2)=394, ออกเลขเพิ่ม=3 → 560

ม.58/2 และ ม.18/1ก: เล่มไม่มียอด → ใส่ dimension ค่า 0 ไว้รองรับ

## A4. ชั้น Service

```csharp
public interface IComplaintStatsService {
    Task<StatsSnapshot> GetSnapshotAsync(StatsFilter filter, CancellationToken ct = default);
}
```

**StatsFilter** (013+015): `YearMode, Year, CompareYear?, Type?, Status?, Zone?, Province?, Period?`
- `YearMode` กำหนดช่วงวันที่จาก `ReceivedAt`: Fiscal = 1 ต.ค.–30 ก.ย. / Calendar = 1 ม.ค.–31 ธ.ค.

**StatsSnapshot** คืนก้อนเดียวพร้อม render:
`Kpi, YearlyTrend, Monthly(เดือน+ไตรมาส), BySection, LegalType, Channels(17+Top5), Zones, Rows(หลังกรอง), GeneratedAt`

Logic `SeedComplaintStatsService`: construct → gen rows 1 ครั้ง (cache); `GetSnapshotAsync` → apply filter → group เป็น view-models; `YearlyTrend` จาก constant + เสียบปีปัจจุบัน; `GeneratedAt = DateTime.Now`

สลับ API จริง: เขียน `ApiComplaintStatsService : IComplaintStatsService` → DI สลับบรรทัดเดียวใน `Program.cs` `.razor` ไม่แตะ
