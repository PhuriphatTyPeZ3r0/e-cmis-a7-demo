# V6 Fullscreen Redesign — Design Spec

**วันที่:** 2026-06-11 · **สถานะ:** อนุมัติแล้ว (ผ่านการคุยใน session)

## เป้าหมาย

จัดผัง layout V6 ของ `/analytics` ใหม่ให้**เต็ม viewport พอดีทุกขนาดจอ** (MacBook → จอใหญ่) ลดความรก โดย**คงธีมเดิมทั้งหมด** (สี การ์ด panel-glow ฟอนต์ ข้อมูล)

## โครงใหม่ — "Command Grid"

CSS Grid เดียวสูง `100dvh − topbar`:

| พื้นที่ | เนื้อหา |
|---|---|
| คอลัมน์ซ้าย (span ทุกแถว, ~30%) | การ์ดแผนที่ฮีทแมพ (เต็มสูง) + drilldown ม.62 เดิม |
| แถว 1 ขวา | KPI 6 ใบ (4 ใบเดิม + สะสม 42,510 + รับปี 2569 = 560) |
| แถว 2 ขวา | กราฟ SLA เปรียบเทียบ (มี dropdown ตัวกรองในหัวการ์ด) ∥ แจ้งเตือนคดีค้าง SLA & AGEING |
| แถว 3 ขวา | Donut Top 5 ช่องทาง + กล่องผลค้นหาคดี ∥ ตารางรายการคดีรับใหม่ |

## การตัด/ย้าย

- **ตัด:** แถบประกาศ "สำนวนคงค้าง..." (ตัวเลขย้ายเข้า KPI)
- **เก็บตามที่ user เลือก:** donut Top 5, กล่องผลค้นหาคดี, dropdown ตัวกรองประเภทเตือน (ย้ายเข้าหัวการ์ดกราฟ)
- ไม่แตะ V1–V5, ไม่แตะ @code logic (ยกเว้นจุด bind ที่ markup ย้าย)

## กลไก responsive

- แถว/คอลัมน์ใช้ `minmax(0, fr)` → ขยาย-หดตามจอ ไม่มี scroll ระดับหน้า
- ตาราง/รายการเตือนใช้ scroll ภายในการ์ด (`.an-scroll` เดิม)
- ฟอนต์ตัวเลข KPI และ padding ใช้ `clamp()`
- จอแคบ < 1100px: พับเป็นคอลัมน์เดียว (แผนที่สูงคงที่ ~420px แล้วการ์ดอื่นต่อท้าย, อนุญาต scroll แนวตั้งปกติ)

## Verification

Playwright screenshot ที่ 1440×900 และ 1920×1080: ไม่มี body scroll (จอ ≥1100px), การ์ดครบ 7 ส่วน, heatmap ยังคลิก drill-down ได้, เทสเดิม 33 ตัวผ่าน, build 0 errors
