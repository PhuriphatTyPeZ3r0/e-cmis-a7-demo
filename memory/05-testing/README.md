# E-CMIS End-to-End Automation Testing
Automation test suite built with Python, Playwright, and Pytest.

## Structure
- `page/`: Page Object Models (POM)
- `tests/`: End-to-end integration and workflow test suites
- `pytest.ini`: Pytest configuration

## Running Tests
```bash
# Activate virtual environment
.venv\Scripts\activate

# Run test suite
pytest -v
```
