# E-CMIS Agent Service
Node.js / TypeScript Service for MCP Integration & Gemini AI Capabilities.

## Directory Structure
- `src/index.ts`: Service Entry Point
- `src/apiClient.ts`: HTTP Client for E-CMIS Backend API
- `src/mcpClient.ts`: Model Context Protocol (MCP) Client
- `src/memoryStore.ts`: In-memory state and session cache
- `testMcp.ts`: MCP integration test runner

## Getting Started
```bash
npm install
npm run build
npm start
```
